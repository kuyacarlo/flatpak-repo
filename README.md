# Dock Flatpak repository

This branch publishes the signed OSTree repository served at https://kuyacarlo.github.io/dock-flatpak/.

Add it with `flatpak remote-add --user --if-not-exists dock https://kuyacarlo.github.io/dock-flatpak/dock.flatpakrepo`, then install with `flatpak install dock dev.kuyacarlo.Dock`.
